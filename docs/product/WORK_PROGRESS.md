## Обозначения

- **План** — ещё не начато; **В работе** — есть изменения, но нет полной приёмки; **Частично** — подтверждены только отдельные сценарии; **Готово** — есть проверенный результат и ссылка на доказательство; **Блок** — есть препятствие.
- **CI прошёл** не равно «все пользовательские операции проверены»: Live QA и полный сквозной E2E ведём отдельно.
- Изменения реальных объектов выполняются только в изолированной тестовой БД с именами `QA-WORK-*`.

## Правила актуализации

1. Каждое закрытие задачи: обновить статус, вставить ссылку на PR и подтверждение проверок; не ставить «Готово» до успешной приёмки.
2. Сводные очереди `AH-01...AH-07` раскрывать в подзадачи при начале соответствующего этапа.
3. Для любой операции фиксировать create → edit → link → move → save → reload → delete → audit, включая негативные сценарии.
4. Не отмечать публикацию техрешения как фактическое изменение инфраструктуры: это разные действия.
