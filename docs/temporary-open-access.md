# Временный доступ без пароля

После развёртывания backend и frontend включите серверную настройку
`ARCH_HUB_OPEN_ACCESS=true` в `/etc/architecture-hub.env` и перезапустите
`architecture-hub.service`.

Все посетители адреса получат доступ к реальной архитектуре и её редактированию.
В интерфейсе вместо входа появится «Доступ без пароля». Управление учётными
записями и изменение паролей в этом режиме недоступны. В истории действий
используется общий автор `open-access`.

Существующие настройки пароля, ключей и пользователей не удаляются. Чтобы
вернуть вход, установите `ARCH_HUB_OPEN_ACCESS=false` и перезапустите сервис.
Открытые вкладки утратят возможность обращаться к API без авторизации.
Настройка не включена по умолчанию; клиент не может включить её самостоятельно.

Проверка после перезапуска:

```bash
curl --fail --silent https://test.web-tie.ru/api/auth/mode
```

Ожидается `{"open_access":true}`. Обновите страницу хаба.
