# Architecture Hub — журнал выполнения плана

**Начало:** 2026-11-21. **Область:** внутренний бесплатный продукт; коммерциализация не входит в текущие критерии приёмки.  
**Порядок выпуска:** разработка в отдельном PR → успешный полный CI → слияние в `main` → автоматическая публикация на тестовый сервер → Live QA. На production автоматически не выкладываем.  
**План:** [DELIVERY_ROADMAP.md](DELIVERY_ROADMAP.md) · **Проверки:** [ACCEPTANCE_SCENARIOS.md](ACCEPTANCE_SCENARIOS.md).

## Обозначения

- **План** — ещё не начато; **В работе** — есть изменения, но нет полной приёмки; **Частично** — подтверждены только отдельные сценарии; **Готово** — есть проверенный результат и ссылка на доказательство; **Блок** — есть препятствие.
- **CI прошёл** не равно «все пользовательские операции проверены»: Live QA и полный сквозной E2E ведём отдельно.
- Изменения реальных объектов выполняются только в изолированной тестовой БД с именами `QA-WORK-*`.
